Home Assistant Configuration

Add the following to your configuration.yaml:

rest:
  - resource: "http://%HOSTNAME%.local/status"
    scan_interval: 60
    sensor:
      - name: "Led'o'clock Color"
        unique_id: "ledoclock_sensor_color"
        value_template: "{{ value_json.current_color }}"
      - name: "Led'o'clock Brightness"
        unique_id: "ledoclock_sensor_brightness"
        value_template: "{{ value_json.brightness_percent }}"
        unit_of_measurement: "%"
      - name: "Led'o'clock Active LEDs"
        unique_id: "ledoclock_sensor_active_leds"
        value_template: "{{ value_json.current_leds_on }}"
        unit_of_measurement: "LEDs"

rest_command:
  ledoclock_set_color:
    url: "http://%HOSTNAME%.local/set_color?value={{ color }}"
    method: GET

  ledoclock_set_brightness:
    url: "http://%HOSTNAME%.local/set_brightness?value={{ brightness }}"
    method: GET
Advanced usage: API Endpoints
  • POST /colors
    Body: JSON Array [{"name":"orange", "hex":"#ff4000"}]
  • POST /schedule
    Body: JSON Array [{"time":"HH:MM", "color":"red", "countdown":true, "days":[true,true,true,true,true,true,true]}]
  • GET /set_brightness
    Param value: 0-100
  • GET /set_color
    Note: this will force the color until the next scheduled change.
    Param value: off, red, orange, green, etc.
  • GET /set_timezone
    Param value: TZ string (e.g. CET-1CEST...)
  • GET /status
    Returns JSON status
  • POST /firmware_update
    Check for new firmware and install it if available
